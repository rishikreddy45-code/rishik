# Super AI

Next.js 16 starter for the Super AI brand. Run `npm install` then `npm run dev`. Deploy by importing this repository into Vercel. Add `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_WEB3FORMS_KEY` when configured.

The full multi-page handoff with all 14 image assets is available in the downloadable project archive supplied in the ChatGPT conversation.
